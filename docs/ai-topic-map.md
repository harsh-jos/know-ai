# AI Concepts Reading Map

This file is the research-backed source map for the personal reader. The app should not feel like a course platform. It should feel like a private stack of excellent short readings, ordered enough to compound, but small enough to keep returning to.

## Content Standard

- Each topic should teach one durable idea.
- Prefer 3-6 minute reads.
- Use the 80/20 rule: explain the concept that unlocks the most future understanding.
- Avoid generic motivational filler, fake profundity, and "AI slop" phrasing.
- Use examples, cautions, or questions only when they naturally make the note better.
- If a topic cannot be explained crisply, split it.
